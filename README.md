   # 現場点呼・配車管理ダッシュボード (Dispatch & Rollcall Dashboard)

既存の社内システム（VBA/Access）のバックエンドには手を加えず、フロントエンドの入力インターフェースと拠点内のデータ可視化をGoogle Workspace (スプレッドシート) でモダン化した業務改善テンプレートです。

## 解決した課題
- **VBAの属人化解消**: メンテナンスが困難になっていたVBAの依存度を下げ、GASとスプレッドシートによるオープンな運用へ移行。
- **レガシーシステムとの共存**: 既存のAccess/VBAバックエンドを改修するリスクとコストを回避。
- **アナログ業務の削減**: 電話での点呼や終了時の口頭報告のデータ操作性をダッシュボード管理にし、月次データベース投入までのフローを自動化。

## システム構成と機能

### 1. 現場向けUI：極小入力のアプローチ
- **QRコード & Googleフォーム起動**: アプリのインストール不要。各現場のQRを読み取るだけでフォームが起動。
- **最小構成の入力設計**: プルダウンや番号入力など、現場のITリテラシーに配慮したUIで入力ミスを防止。

### 2. 拠点向けダッシュボード：ハブとしてのスプレッドシート
- **リアルタイム連携**: 現場からのフォーム送信をトリガーに、スプレッドシートへ即時反映（通知）メンバー共有。
- **ポータル機能**: 各種権限者用シートや、社員向け情報ストック用シートへのリンク集約ハブとして機能。（機能は簡略化の為、項目のみ表示）
- **可読性の向上（UI/UX）**: 曜日（日曜）ごとの自動色分けや、ステータスに応じた条件付き書式を設定し、直感的なオペレーションを実現。
