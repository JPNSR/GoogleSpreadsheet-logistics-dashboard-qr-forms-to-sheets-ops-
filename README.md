# 現場点呼・配車管理ダッシュボード (Dispatch & Rollcall Dashboard)

既存の社内システム（VBA/Access）のバックエンドには手を加えられない場合のフロントエンドの入力インターフェースと拠点内のデータ可視化を Google Workspace（スプレッドシート & Google フォーム）でモダン化したテンプレートです。

---

## 🚀 導入方法

プログラミングや複雑な設定は不要です。以下のリンクからご自身の Google ドライブにシステム一式を即座に複製・展開できます。

👉 **[配車管理ダッシュボード一式をコピーして導入する](https://docs.google.com/spreadsheets/d/1WEnFSQ1wAWwDVw7rb8MkloGSRmBVEZQy9L8IwBUZr-A/copy)**

1. 上記リンクをクリックします。
2. 「ドキュメントのコピーを作成しますか？」と表示されたら、**「コピーを作成」** をクリックします。
3. ご自身の Google ドライブ内にスプレッドシート自動生成されます。
4. コピーされたスプレッドシートの上部メニュー `拡張機能` > `フォーム` > `ライブフォームへ移動` から現場入力用フォームの URL を取得し、QRコードなどで現場へ共有してください。
---

## 解決した課題
- **VBAの属人化解消**: メンテナンスが困難になっていたVBA（Excelファイル）への依存度を下げ、Googleフォームとスプレッドシートによるオープンで保守しやすい運用へ移行。
- **レガシーシステムとの共存**: 既存のAccess/VBAバックエンドを大規模改修するリスクとコストを回避しつつ、現場UIをモダン化。
- **アナログ業務の削減**: 前日管理表作成や終了時の口頭報告を可能な人員はフォーム入力へ移行し、ダッシュボードでの一元管理と月次データ集計までの流れを効率化。（電話などのレガシーなシステムへも対応可能）
- **顧客への情報展開**: スプレッドシートアプリから、当スプレットシートへの動線を利用して、出先での情報照会・回答が可能
- **拠点内情報の一元管理ダッシュボード**: 各種URLや社内共有フォルダ（Excelファイルの共有）複数ファイルへのまたがりを当ダッシュボードを利用して、URL・各拠点情報を管理、周知事項の記載など、情報記載先の統一

## システム構成と機能

### 1. 現場向けUI：極小入力のアプローチ
- **QRコード & Googleフォーム起動**: アプリのインストール不要。現場の端末やスマホでQRコードを読み取るだけで入力フォームが起動。
- **最小構成の入力設計**: プルダウンや番号入力など、現場のITリテラシーに配慮した設計で入力ミスを防止。

### 2. 拠点向けダッシュボード：ハブとしてのスプレッドシート
- **リアルタイム連携**: 現場からのフォーム送信内容が、スプレッドシート（WEBフォーム回答）へ即座に自動集約・メンバー共有。
- **ポータル機能**: 各種権限者用シートや、社員向け情報ストック用シートへのアクセスを集約するハブとして機能。（※テンプレートでは項目枠を配置）
- **可読性の向上（UI/UX）**: 曜日（日曜）ごとの自動色分けや、ステータスに応じた条件付き書式を設定し、直感的な運行管理オペレーションを実現。

## 💡 注意事項
- テンプレート内の「ドライバー情報」タブなどには初期設定用のダミーデータが入っています。運用に合わせて実際のデータに書き換えてご活用ください。
- 組み込まれている参照数式や条件付き書式が崩れないよう、行の削除・追加時はご注意ください。
- 特定の社内システムよりCSVで払い出される（VBA/エクセル）のテーブルカラムを元データ整形が行われる為、参照データが異なる場合は各カラムなどを調整する必要があります。
- グーグルフォームに関しては内蔵されていない為、別途設定が必要です。
